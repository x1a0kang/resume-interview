### 深启智能｜教学 Agent 与教学资源 RAG

**AI 应用开发** ｜ 2025.08—2026.08

**项目简介：**以慧批的批改与学情数据作为业务事实、教学资料作为讲解依据，面向教师备课讲评、学情分析、学生答疑与家长学情分析，开发教学 Agent 与教学资源 RAG 应用层，提供循环任务编排与工具调用、多轮对话、长期记忆和2W+份知识文档管理与检索。

**技术栈：**Java、Spring Boot、LangGraph、ReAct、MySQL、MongoDB、Redis、SSE、RAG

**核心职责：**

- **Agent 任务编排：**基于 LangGraph 构建 ReAct 教学 Agent，串联模型推理、工具调用与结果反馈，支持跨作业分析、教学答疑等多步骤任务；通过 Java 后台消费 Python 模型流并以 SSE 推送，将任务执行与前端连接解耦，支持断连后继续生成并持久化完整结果。
- **业务工具封装：**面向教学任务重新组织既有产品能力，将批改、题目标注、学情统计及教学资料检索封装为高层业务工具，按用户角色限定可用范围；由业务服务完成分数、正确率和错题分布等确定性计算，模型基于工具结果进行分析与解释，保持回答与平台数据口径一致。
- **人工确认机制：**为修改类工具引入 Human-in-the-loop 流程，在执行前暂停任务并向用户展示待执行操作，确认后继续调用工具；将用户授权作为修改操作的执行前置条件，避免模型直接变更业务数据。
- **任务状态恢复：**基于 LangGraph Checkpoint 保存人工确认节点的执行状态，保留对话上下文及待执行工具信息；接收用户确认后，从暂停位置恢复执行，衔接工具调用与后续推理，避免重新运行完整任务流程。
- **教学资料入库：**基于采购的万余份教学资料，支持Word，PDF，PPT等多种类型资料切分、Embedding 与 VikingDB 索引链路；按章节及语义组织 Chunk，引入大模型优化处理文档中的表格和图片；解析并保存教材版本、学科、年级、学期作为元数据，形成可追溯的教学依据。
- **混合检索优化：**实现 BM25 与 Dense 双路召回，通过 RRF 融合去重并使用 Rerank 精排；按学段、学科、年级及教学资料版本限定候选范围，将题目与候选内容的知识点匹配情况纳入相关性评分，减少表述相近但考查内容不同的资料干扰。

### 深启智能｜慧批 AI 作业批改与智能学情平台

**后端负责人** ｜ 2025.08—2026.08

**项目简介：**面向学校教学场景，提供纸质作业定标、识别、自动批改及结果回写功能；汇总得分、错题和知识点情况，支持学生与班级学情分析，帮助教师了解学习表现、调整教学。

**技术栈：**Java、Spring Boot、MySQL、MongoDB、Redis、RabbitMQ

**核心职责：**

- **知识点打标优化：**针对每学科近几百个分层知识点一次输入模型导致耗时长、易漏标的问题，改为逐层筛选：从每层节点中选出 1至3 个节点，再按所选节点展开子节点直至叶子，多次模型调用，降低思考强度，单题平均耗时由超过 2 分钟降至约 30 秒。
- **异步重批一致性：**针对连续修改答案时旧任务后完成、覆盖新结果的线上问题，通过日志定位异步回调乱序，在既有 RabbitMQ 链路中新增 version 校验并拦截旧结果，上线后未再出现相同问题。
- **答题卡批改：**针对平台缺少答题卡批改能力的问题，协同算法侧打通生成、识别、批改与结果回写，同时后端根据作业识别结果，提供生成答题卡并导出PDF功能，为老师提供非标准试卷的考试和批改能力。
- **采分点与多解法：**针对局部步骤错误或采用非预设解法导致失分的问题，新增后端数据字段及前端交互，改造定标、重批接口与算法协议；协同算法侧实现先识别解法、再按对应采分点评分，覆盖过程分与不同解题路径；上线后教师反馈的“解法正确却被判错”问题明显减少。
- **学情分析 AI 建议：**针对缺少作业后分析能力的问题，开发作业提交情况、得分、错题、知识点和学科素养的统计分析功能，按学生、班级、老师、学校和区域等维度聚合，生成周期报告，为教学看板与上层应用提供确定性数据。同时根据统计分析结果，AI 异步生成学生学习与教师教学建议。上线后教师使用评价很高，并根据教师反馈为其增加推荐练习与 PDF 导出。
- **后台管理与维护：**全栈开发数据管理平台，支持知识点与教材版本等配置管理，用户反馈收集展示及处理，查看作业批改结果，可直接修改答案、触发重新批改等运营维护操作，供内部研发与运营十余人日常运维使用。
