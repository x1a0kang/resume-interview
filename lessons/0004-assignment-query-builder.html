同一个算式，可能对应不同教学主题

本课目标：用题意与已有解法组织检索主题，再将主题转成教材和教参查询。

聊天 Agent 决定何时调用教学资料检索；检索工具中的 Query Builder 把作业内容转成查询。固定按钮 Workflow 则可以直接执行同一检索工具。Query Builder 使用 LLM，不会自动使固定 Workflow 成为 Agentic RAG。

题目教学检索主题
Q1：3/4 ÷ 2/5
Q2：5/6 ÷ 1/3		分数除法计算：除法转为乘倒数
Q3：3/4 升果汁，每杯 1/8 升，能装几杯？已知总量与每份量，求份数
Q4：绳子全长的 2/5 是 3/4 米，求全长已知部分量与对应分率，求整体

Q1 与 Q4 的算式相同，均为 3/4 ÷ 2/5。但 Q4 的教学重点包括单位1和部分—整体关系。仅匹配算式不能完成这一区分。

主题怎样变成 Query

将教师任务对应的资料需求加到主题上：教材方法、算理、教参重难点与课堂引导。先依据输入确定关系，再提出检索需求；不要预先编造教材结论。

Q1、Q2 → 分数除法计算
  → 分数除法转化为乘倒数的计算法则与算理

Q3 → 总量÷每份量求份数
  → 分数除法中已知总量和每份量求份数的数量关系

Q4 → 部分量÷对应分率求整体
  → 已知一个数的几分之几是多少求这个数，单位1的识别方法

规则与 LLM 各自需要什么

规则可以匹配已有解析中的“除数取倒数”“总量÷每份量”“单位1”等明确表达，再套查询模板。解析没有这些表达时，规则应返回未识别，不能假装从运算符推导出了题意。LLM 可以结合题干与解法完成语义归纳，但仍需服务端验证题号、数量、长度和输出结构。
