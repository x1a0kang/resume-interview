## 本次梳理结论

这不是两个彼此独立的小工具，而是一套“**教师作业标准化 → 学生作答识别 → 逐空批改 → 结果回写/查询**”的异步闭环：

- **HP-Grading**：以 Java/Spring Boot 实现业务中台。它接收教师、学生业务动作，保存任务、题目、图片与结果，投递/消费 MQ 消息，维护状态、重试、通知和供前端调用的结果查询。
- **xEduAI**：以 Python mono-repo 实现视觉与大模型能力。它按任务路由完成 OCR、题目结构化、答案解析/解题、学生作答识别、非作文/作文批改，并输出标准 JSON。
- **耦合方式**：RabbitMQ 传递异步任务与结果；`request_id`、题目/空 ID、版本号和任务状态将两侧串成可追踪链路。
